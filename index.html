Scruby Companion - Gameplay Instructions

Advanced MMORPG Companion Mod for Hytale

📺 For screenshots, trailer, and visuals, see the full mod page on CurseForge:

https://www.curseforge.com/hytale/mods/scruby-companion

Quick Start

  1. Install the Scruby Companion mod and the HyUI dependency mod.
  2. Enable both in your game settings under Mods.
  3. Join your world. Your first Scruby will automatically spawn and start following you.
  4. Open the Scruby menu anytime with /scruby-menu or look at him and press F.

That's it - you're ready to play.

Useful Commands

  • /scruby-menu - open the main Scruby UI
  • /scruby - list all player commands and settings
  • /scruby-admin - server admin commands (op-mode required); use it to instantly level up and more

First Steps (Level 1–5)

Your Scruby starts at level 1 with no class.

  • Kill mobs together. Scruby earns XP from your kills and his own.
  • First kills on a new NPC type give 2× XP (Discovery System). Explore actively.
  • At level 5, the path selection unlocks. Choose between DPS, Healer, or Tank.

Choosing a Path (Level 5)

Open the Scruby menu and select your path:

  • DPS - high damage output, ranged abilities
  • Healer - keeps you alive with regeneration and healing skills
  • Tank - soaks up damage, draws aggro, high HP focus

Each path has its own skill set and visual evolution.

Combat Modes

Scruby has two combat modes you can switch anytime from the character tab:

  • Attack Mode - Scruby attacks every hostile NPC within 20 blocks
  • Guard Mode - Scruby only attacks the enemies you target

Skilling Your Scruby

  • You earn 2 attribute points per level (Vitality, Strength, Zeal)
  • At level 12 and level 18, you choose 1 skill each time
  • Total of 22 skills available across all paths

Skills Overview

All 22 skills across the three paths. Combat Instinct is the shared starter passive.

DPS

  • Combat Instinct - passive combat bonus
  • Burning Arrows - 1 DMG/s in 8-block radius
  • Focus Fire - +1 DMG/s on shared target
  • Predator Senses - radius 8 → 15; Burning Arrows → 1.5/s
  • Double Shot - 5 burst every 8s
  • Poison Arrows - +1 DMG/s additional DoT
  • Deadly Precision - double DMG vs enemies <30% HP
  • Suppressive Fire - radius doubled, tick DMG normalized to 0.5/s

Healer

  • Combat Instinct - passive combat bonus
  • First Aid - heals 20% MaxHP below 40% HP, 15s CD
  • Regeneration - +1 HP/s
  • Guardian's Blessing - +20 MaxHP within 15 blocks
  • Protection Spell - heals 40% MaxHP below 25% HP, 30s CD
  • Purification - regen → 1.5 HP/s
  • Life Bond - +0.5 DMG/s, 50% heals you
  • Emergency Rescue - 50% heal + AoE shockwave below 15% HP, 30s CD

Tank

  • Combat Instinct - passive combat bonus
  • Provocation - 1 DMG/s in 8 blocks (aggro)
  • Thick Fur - +16 MaxHP
  • Retribution - 50% of dmg to Scruby hits nearest enemy
  • Iron Skin - +25 MaxHP + 3 HP/s self-heal (>25% HP)
  • Thorns - 35% AoE retribution + 10 MaxHP
  • War Cry - 4 DMG AoE burst every 8s in 10 blocks
  • Loyal Protector - 30% of your damage goes to Scruby

Equipping Armor

  • Open the Scruby menu and go to the Item Transfer tab
  • Drag any native Hytale armor onto Scruby
  • Each piece adds HP and renders visually on Scruby's model

Scruby Inventory and Auto-Loot

  • Scruby has a built-in 20-slot inventory
  • He automatically picks up items dropped by NPCs he helped kill
  • Transfer items to and from Scruby via the Item Transfer tab

Base Guarding

  • Open the Scruby menu and set Scruby to "stationed" mode at your base location
  • While stationed, you can switch between two behaviors anytime:
    • Patrol Mode - Scruby actively defends the area, kills enemies within range, and stockpiles loot
    • Stay Mode - Scruby waits peacefully at the base and does not attack
  • Return any time to collect what he gathered

Evolution Stages

Scruby visually evolves at:

  • Level 5 (after path selection)
  • Level 13
  • Level 20 (Prestige evolution)

Endgame: The Prestige Fight

At max level (20), the Prestige Fight unlocks:

  • Open the Scruby menu and challenge the Prestige boss
  • The boss has 500 HP and deals 1 AOE damage per second
  • Win: unlock the Legendary Prestige Skin (a status symbol on multiplayer servers)
  • Lose: no second chance (server admins can grant a retry via /scruby-admin)

Server Admins

Configure XP rates, respawn delays, prestige toggles, and more in:

Hytale-Dedicated-Server/mods/CompanionMod_ScrubyCompanion/scruby-config.json

For Mod Developers (CompanionConnect API)

Other Hytale companion mods can coexist peacefully with Scruby. Scruby's AoE skill targeting (Healer-AoE, DPS-Burst, Tank-Taunt, etc.) automatically skips entities from any plugin that follows the convention below. No registration, no runtime handshake, no plugin dependency required for the basic case.

Easiest path - role naming only

Pick any name for your companion's NPC role and include the substring _CompanionConnect somewhere in it. That is the entire requirement.

Examples that match:

MyMod_Wolf_CompanionConnect
Awesome_Pet_CompanionConnect_Aggressive
SomeMod_Companion_CompanionConnect_Stationed

As soon as your plugin is loaded alongside Scruby, Scruby's AoE skills will leave your entities alone. Vanilla Hytale roles do not contain this substring, so there is no risk of false positives on regular mobs.

Optional - query Scruby from your code

If you want the inverse (your skills should skip Scrubys in their own targeting), Scruby ships a small read-only static facade. Add Scruby's JAR as a compile-only dependency. Use the latest release from CurseForge.

// build.gradle
dependencies {
  compileOnly files('libs/ScrubyCompanion-vX.Y.Z.jar')
}

Then in your skill or targeting code:

import org.example.plugin.ScrubyCompanionAPI;

if (ScrubyCompanionAPI.isScrubyCompanion(store, ref)) {
    continue; // do not target a Scruby
}

compileOnly means the JAR is only used for compilation - it is not bundled into your mod. At runtime the actual Scruby JAR is loaded from the server's mods folder.

Available methods

  • isScrubyCompanion(store, ref) - true if the entity's NPC role name contains Scruby_
  • isCompanionConnectNpc(store, ref) - true if the role name contains _CompanionConnect
  • getScrubyOwner(ref) - returns Optional<UUID> of the owning player, for live registered Scruby companions only
  • getConventionSuffix() - returns the literal convention string "_CompanionConnect"

The facade is read-only and side-effect-free. If Scruby is not on the server, the owner-lookup returns Optional.empty() rather than throwing.

What the protocol does NOT do

  • It does not modify direct auto-attack damage. That is governed by Hytale's NPC-Role attitude system, configured in role definitions themselves.
  • It does not differentiate between same-owner and different-owner companions in PvP scenarios.
  • It does not publish lifecycle events (spawn, despawn, level-up) for other plugins to subscribe to.

These are deliberate omissions. Extensions are possible if there is real cross-mod demand.

Reflection alternative (no JAR dependency)

If your mod must work standalone (without Scruby installed), use reflection instead of a compile-time dependency:

try {
    Class<?> api = Class.forName("org.example.plugin.ScrubyCompanionAPI");
    boolean isScruby = (boolean) api
        .getMethod("isScrubyCompanion", Store.class, Ref.class)
        .invoke(null, store, ref);
    if (isScruby) continue;
} catch (ClassNotFoundException scrubyNotInstalled) {
    // Scruby is not on this server - nothing to skip.
} catch (Exception ignored) { }
